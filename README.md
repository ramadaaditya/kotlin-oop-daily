# kotlin-oop-daily

Daily Kotlin OOP practice, built **without AI**. Goal: build a multi-class Kotlin app from a blank file by end of Feb 2027.

## Rules
1. No AI chat, no AI code completion (disable it in Android Studio).
2. Reference only kotlinlang.org docs and official sources.
3. Write first, check docs second.
4. Commit every day.

## Daily routine (~1 hour)
1. 10 min - Recall: blank file, write yesterday's topic from memory.
2. 35 min - Learn one new concept, write 2-3 small programs.
3. 10 min - Spaced review: redo one kata (day 1, 3, 7, 21 after learning).
4. 5 min - Add a line to LOG.md, note errors in notes/mistakes.md, commit.

## Files
- CHECKLIST.md - 20-week plan with daily boxes
- LOG.md - one line per day
- REVIEW.md - spaced repetition tracker
- katas/ - topic drills to redo from scratch
- projects/ - bigger projects
- daily/ - your daily practice files (daily/YYYY-MM/dayNN_topic.kt)
- notes/mistakes.md - errors and lessons
